Abstract

In modern polytechnic technical education under the State Board of Technical Education (SBTE), Kerala (Revision 2021), academic performance is evaluated through a credit-based grading scheme utilizing Semester Grade Point Average (SGPA) and Cumulative Grade Point Average (CGPA) across 120 total credits. Manual computation of these scores is tedious, prone to human error, and complicated by varying credit weights per course, laboratory, elective streams, and specific percentage conversion factors (GPA × 9.5).

PolyCGPA is a lightweight, responsive, zero-dependency, web-based computational application designed specifically to automate and streamline SGPA and CGPA computation for Computer Engineering diploma students. The application features complete, pre-configured syllabi for all six semesters, dynamic elective selectors for Semesters 5 and 6, instant real-time mathematical evaluations, visual grade breakdowns, backlog detection, and printable scorecards.

According to the official curriculum regulations of the State Board of Technical Education (SBTE), Kerala (Revision 2021), academic evaluations are assigned letter grades mapped to numerical grade points on a 10-point scale:

3. Mathematical Formulations & Algorithms

3.1 Semester Grade Point Average (SGPA)

SGPA evaluates academic achievement for a single semester. It represents the credit-weighted average of the grade points secured across all registered subjects in that semester.

SGPA Calculation Formula:
SGPA = Σ(Ci × Gi) / Σ(Ci)

Where Ci is the credit assigned to course i, and Gi is the numerical grade point earned in course i.

3.2 Cumulative Grade Point Average (CGPA)

CGPA evaluates overall academic performance across all completed semesters (up to 6 semesters, 120 total credits). It is weighted by the credit weight of each completed semester.

CGPA Calculation Formula:
CGPA = Σ(Sk × Ck) / Σ(Ck)

Where Sk is the SGPA achieved in semester k, and Ck is the total credits of semester k.

3.3 Percentage Conversion Formula

Under SBTE Kerala regulations, the official formula to convert Grade Point Average into equivalent percentage marks is:

Percentage Conversion:
Equivalent Percentage (%) = GPA × 9.5

8.1 js/calculator.js — Core Mathematical Engine 
  1 /**
  2  * PolyCGPA - Core Calculation Engine

  5 const Calculator = {
  6     /**
  7      * Calculate SGPA from subjects
  8      * SGPA = Σ(Credits * Points) / Σ(Credits)
  9      */
 10     calculateSGPA(subjects) {
 11         if (!Array.isArray(subjects) || !subjects.length) {
 12             return { sgpa: 0, totalCredits: 0, totalPoints: 0, percentage: "0.0", academicClass: "N/A", isValid: false };
 13         }
 14 
 15         let totalCredits = 0;
 16         let totalPoints = 0;
 17         let hasBacklog = false;
 18 
 19         for (const s of subjects) {
 20             const credits = parseFloat(s.credits) || 0;
 21             const points = typeof s.points === "number" ? s.points : (typeof DataService !== "undefined" ? DataService.getGradePoints(s.grade) : 0);
 22             if ((s.grade || "").toUpperCase() === "F" || points === 0) hasBacklog = true;
 23             totalCredits += credits;
 24             totalPoints += (credits * points);
 25         }
 26 
 27         if (totalCredits <= 0) {
 28             return { sgpa: 0, totalCredits: 0, totalPoints: 0, percentage: "0.0", academicClass: "N/A", isValid: false };
 29         }
 30 
 31         const sgpa = Math.round((totalPoints / totalCredits) * 100) / 100;
 32         const percentage = (sgpa * 9.5).toFixed(1);
 33         const academicClass = hasBacklog ? "Fail / Re-appear (Backlog)" : (typeof DataService !== "undefined" ? DataService.getClass(sgpa) : "Pass");
 34 
 35         return {
 36             sgpa: parseFloat(sgpa.toFixed(2)),
 37             totalCredits: parseFloat(totalCredits.toFixed(1)),
 38             totalPoints: parseFloat(totalPoints.toFixed(2)),
 39             percentage,
 40             academicClass,
 41             isValid: true
 42         };
 43     },
 44 
 45     /**
 46      * Calculate CGPA across semesters
 47      * CGPA = Σ(SGPA * Credits) / Σ(Credits)
 48      */
 49     calculateCGPA(semesters) {
 50         if (!Array.isArray(semesters) || !semesters.length) {
 51             return { cgpa: 0, totalCredits: 0, totalPoints: 0, percentage: "0.0", academicClass: "N/A", completedSemesters: 0, isValid: false };
 52         }
 53 
 54         let totalCredits = 0;
 55         let totalPoints = 0;
 56         let completed = 0;
 57 
 58         for (const s of semesters) {
 59             if (s.included === false) continue;
 60             const sgpa = parseFloat(s.sgpa);
 61             const credits = parseFloat(s.credits);
 62             if (!isNaN(sgpa) && !isNaN(credits) && credits > 0) {
 63                 totalCredits += credits;
 64                 totalPoints += (sgpa * credits);
 65                 completed++;
 66             }
 67         }
 68 
 69         if (totalCredits <= 0 || completed === 0) {
 70             return { cgpa: 0, totalCredits: 0, totalPoints: 0, percentage: "0.0", academicClass: "N/A", completedSemesters: 0, isValid: false };
 71         }
 72 
 73         const cgpa = Math.round((totalPoints / totalCredits) * 100) / 100;
 74         const percentage = (cgpa * 9.5).toFixed(1);
 75         const academicClass = typeof DataService !== "undefined" ? DataService.getClass(cgpa) : "Pass";
 76 
 77         return {
 78             cgpa: parseFloat(cgpa.toFixed(2)),
 79             totalCredits: parseFloat(totalCredits.toFixed(1)),
 80             totalPoints: parseFloat(totalPoints.toFixed(2)),
 81             percentage,
 82             academicClass,
 83             completedSemesters: completed,
 84             isValid: true
 85         };
 86     }
 87 };

9. Conclusion & Future Roadmap

9.1 Conclusion

The PolyCGPA application successfully resolves the challenges associated with credit-weighted academic calculations under the SBTE Kerala Revision 2021 curriculum for Diploma in Computer Engineering.

By packaging the entire 6-semester syllabus, elective bindings, grade points, and percentage conversion formulas into an intuitive, ultra-fast client-side web application, students and faculty can instantly evaluate academic standings with 100% mathematical precision.

9.2 Future Roadmap

  • Multi-Branch Expansion: Adding preloaded curricula for Civil, Mechanical, Electrical, and Automobile Engineering.
  • PDF Transcript Generator: Client-side PDF export of individual semester grade sheets using embedded jsPDF.
  • Offline PWA Support: Adding Service Workers to enable full offline support as an installable Progressive Web App.
